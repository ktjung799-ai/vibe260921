## 1. 배경 및 목적

개발자 정경태의 역량과 작업물을 한곳에서 보여주는 개인 프로필 웹사이트를 만든다. 방문자가 "누구이고, 무엇을 할 수 있으며, 어떻게 연락하는지"를 1분 안에 파악하는 것이 목적이다.

### 목표
- 주 개발 분야(바이브코딩, Python, HTML5)를 명확히 전달한다.
- 실제 만든 결과물(데모)을 바로 실행해 볼 수 있게 한다.
- 이메일을 통한 연락 경로를 제공한다.

### 비목표 (이번 범위 제외)
- 로그인/회원가입, 관리자 페이지
- 서버 및 데이터베이스 (정적 사이트로 구성)
- 블로그 CMS, 다국어 지원

## 2. 대상 사용자

| 사용자 | 방문 목적 |
|---|---|
| 채용 담당자 / 협업 제안자 | 역량과 경험 확인, 연락 |
| 동료 개발자 | 작업물과 코드 참고 |
| 일반 방문자 | 바이브코딩 결과물 체험 |

## 3. 핵심 콘텐츠

### 3.1 소개 (Hero)
- 이름: 정경태
- 한 줄 소개: 바이브코딩으로 아이디어를 빠르게 동작하는 결과물로 만드는 개발자
- 주요 버튼: `작업물 보기`, `연락하기`

### 3.2 기술 스택 (Skills)
| 분야 | 설명 |
|---|---|
| 바이브코딩 | AI와 대화하며 기획부터 구현까지 빠르게 만드는 개발 방식 |
| Python | 자동화, 데이터 처리, 게임/도구 제작 |
| HTML5 | HTML5 / CSS3 / JavaScript 기반 웹 페이지 및 Canvas 게임 |

### 3.3 작업물 (Projects)
카드 형태로 나열하며 각 카드는 제목, 한 줄 설명, 사용 기술 태그, 실행/보기 링크를 가진다.

| 작업물 | 기술 | 설명 |
|---|---|---|
| Snake 게임 | Python (tkinter) | 방향키로 조작하는 뱀 게임 |
| Tetris 게임 | HTML5, CSS3, JavaScript | 줄 삭제 효과가 있는 테트리스 (Canvas) |
| 개발자 프로필 사이트 | HTML5, CSS3, JavaScript | 본 사이트 |

> 이후 작업물은 카드만 추가하면 확장되도록 구성한다.

### 3.4 연락 (Contact)
- 이메일: ktjung@kird.re.kr (`mailto:` 링크, 클릭 시 메일 작성 창 열기)
- 이메일 주소 복사 버튼

## 4. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| F-01 | 단일 페이지에 소개/기술/작업물/연락 섹션을 순서대로 배치한다 | 필수 |
| F-02 | 상단 내비게이션으로 각 섹션에 부드럽게 스크롤 이동한다 | 필수 |
| F-03 | 작업물 카드에서 각 데모를 새 탭 또는 페이지 내에서 실행할 수 있다 | 필수 |
| F-04 | 이메일 링크(`mailto:`)와 주소 복사 기능을 제공한다 | 필수 |
| F-05 | 모바일, 태블릿, 데스크톱에서 레이아웃이 맞게 표시된다 (반응형) | 필수 |
| F-06 | 라이트/다크 테마를 지원한다 (시스템 설정 따름, 수동 전환 가능) | 선택 |
| F-07 | 스크롤 시 섹션이 나타나는 가벼운 애니메이션을 적용한다 | 선택 |

## 5. 비기능 요구사항

- **기술 스택:** HTML5, CSS3, 순수 JavaScript. 외부 프레임워크와 빌드 과정 없이 `index.html`을 열면 동작한다.
- **성능:** 첫 화면 로딩 2초 이내, 페이지 전체 용량 1MB 이하 (이미지 제외).
- **접근성:** 시맨틱 태그 사용, 이미지 `alt`, 키보드 조작 가능, 명도 대비 WCAG AA 이상.
- **호환성:** 최신 Chrome, Edge, Safari, Firefox.
- **SEO:** `title`, `meta description`, Open Graph 태그 설정.

## 8. 디자인 방향

- 깔끔하고 개발자다운 미니멀 스타일, 여백을 충분히 사용한다.
- 강조색 1가지와 중립색으로 구성하고, 코드 느낌의 고정폭 글꼴을 포인트로 쓴다.
- 카드는 마우스를 올리면 살짝 떠오르는 효과를 준다.

## 9. 성공 기준

- 방문자가 첫 화면에서 이름과 주 개발 분야를 바로 확인할 수 있다.
- 모든 작업물 링크가 정상 동작한다.
- 이메일 링크와 복사 버튼이 동작한다.
- 모바일(너비 360px)에서 가로 스크롤 없이 표시된다.

## 10. 진행 계획
